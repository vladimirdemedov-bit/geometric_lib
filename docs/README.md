## Описание функций с примерами вызова

### Прямоугольник (`rectangle.py`)

#### `area(a, b)`
Принимает стороны a и b, возвращает площадь прямоугольника по формуле `S = a*b`

Параметры:
- `a` (`int`) : Длина прямоугольника
- `b` (`int`) : Ширина прямоугольника

Возвращаемое значение:
- `a*b` (`int`) : Площадь прямоугольника

Пример вызова:
```python
res = area(5, 3)
print(res)  # 15
```

#### `perimeter(a, b)`
Принимает стороны a и b, возвращает периметр прямоугольника по формуле `P = 2*(a+b)`

Параметры:
- `a` (`int`) : Длина прямоугольника
- `b` (`int`) : Ширина прямоугольника

Возвращаемое значение:
- `2*(a+b)` (`int`) : Периметр прямоугольника

Пример вызова:
```python
res = perimeter(5, 3)
print(res)  # 16
```

---

### Треугольник (`triangle.py`)

#### `area(a, h)`
Принимает основание a и высоту h, возвращает площадь треугольника по формуле `S = a*h/2`

Параметры:
- `a` (`int`) : Основание треугольника
- `h` (`int`) : Высота треугольника

Возвращаемое значение:
- `a*h/2` (`float`) : Площадь треугольника

Пример вызова:
```python
res = area(6, 4)
print(res)  # 12.0
```

#### `perimeter(a, b, c)`
Принимает стороны a, b и c, возвращает периметр треугольника по формуле `P = a+b+c`

Параметры:
- `a` (`int`) : 1-ая сторона треугольника
- `b` (`int`) : 2-ая сторона треугольника
- `c` (`int`) : 3-яя сторона треугольника

Возвращаемое значение:
- `a+b+c` (`int`) : Периметр треугольника

Пример вызова:
```python
res = perimeter(3, 4, 5)
print(res)  # 12
```

---

### Круг (`circle.py`)

#### `area(r)`
Принимает радиус r, возвращает площадь круга по формуле `S = π*r²`

Параметры:
- `r` (`int`) : Радиус круга

Возвращаемое значение:
- `math.pi * r ** 2` (`float`) : Площадь круга

Пример вызова:
```python
res = area(5)
print(res)  # 78.5...
```

#### `perimeter(r)`
Принимает радиус r, возвращает длину окружности по формуле `C = 2*π*r`

Параметры:
- `r` (`int`) : Радиус круга

Возвращаемое значение:
- `2 * math.pi * r` (`float`) : Длина окружности

Пример вызова:
```python
res = perimeter(5)
print(res)  # 31.4...
```

---

### Квадрат (`square.py`)

#### `area(a)`
Принимает сторону a, возвращает площадь квадрата по формуле `S = a²`

Параметры:
- `a` (`int`) : Сторона квадрата

Возвращаемое значение:
- `a²` (`int`) : Площадь квадрата

Пример вызова:
```python
res = area(4)
print(res)  # 16
```

#### `perimeter(a)`
Принимает сторону a, возвращает периметр квадрата по формуле `P = 4*a`

Параметры:
- `a` (`int`) : Сторона квадрата

Возвращаемое значение:
- `4*a` (`int`) : Периметр квадрата

Пример вызова:
```python
res = perimeter(4)
print(res)  # 16
```
