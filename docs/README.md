# Документация проекта `geometric_lib`

## Общее описание

`geometric_lib` — библиотека для вычисления величин геометрических фигур.

---

## Доступные фигуры

| Фигура | Файл |
| --- | --- |
| Прямоугольник | `rectangle.py` |
| Треугольник | `triangle.py` |
| Круг | `circle.py` |
| Квадрат | `square.py` |

---

## Описание функций с примерами вызова

### Прямоугольник (`rectangle.py`)

#### `area(a, b)`
Принимает стороны a и b, возвращает площадь прямоугольника по формуле `S = a*b`

Параметры:
- `a` : Длина прямоугольника
- `b` : Ширина прямоугольника

Возвращаемое значение:
- `a*b` : Площадь прямоугольника

Пример вызова:
```python
res = area(5, 3)
print(res)  # 15
```

#### `perimeter(a, b)`
Принимает стороны a и b, возвращает периметр прямоугольника по формуле `P = 2*(a+b)`

Параметры:
- `a` : Длина прямоугольника
- `b` : Ширина прямоугольника

Возвращаемое значение:
- `2*(a+b)` : Периметр прямоугольника

Пример вызова:
```python
res = perimeter(5, 3)
print(res)  # 16
```

---

### Треугольник (`triangle.py`)

#### `area(a, h)`
Принимает основание a и высоту h, возвращает площадь треугольника по формуле `S = a*h/2`

Параметры:
- `a` : Основание треугольника
- `h` : Высота треугольника

Возвращаемое значение:
- `a*h/2` : Площадь треугольника

Пример вызова:
```python
res = area(6, 4)
print(res)  # 12
```

#### `perimeter(a, b, c)`
Принимает стороны a, b и c, возвращает периметр треугольника по формуле `P = a+b+c`

Параметры:
- `a` : 1-ая сторона треугольника
- `b` : 2-ая сторона треугольника
- `c` : 3-яя сторона треугольника

Возвращаемое значение:
- `a+b+c` : Периметр треугольника

Пример вызова:
```python
res = perimeter(3, 4, 5)
print(res)  # 12
```

---

### Круг (`circle.py`)

#### `area(r)`
Принимает радиус r, возвращает площадь круга по формуле `S = π*r²`

Параметры:
- `r` : Радиус круга

Возвращаемое значение:
- `pi * r ** 2` : Площадь круга

Пример вызова:
```python
res = area(5)
print(res)  # 78.5398163397
```

#### `perimeter(r)`
Принимает радиус r, возвращает длину окружности по формуле `C = 2*π*r`

Параметры:
- `r` : Радиус круга

Возвращаемое значение:
- `2 * pi * r` : Длина окружности

Пример вызова:
```python
res = perimeter(5)
print(res)  # 31.4159265359
```

---

### Квадрат (`square.py`)

#### `area(a)`
Принимает сторону a, возвращает площадь квадрата по формуле `S = a²`

Параметры:
- `a` : Сторона квадрата

Возвращаемое значение:
- `a**2` : Площадь квадрата

Пример вызова:
```python
res = area(4)
print(res)  # 16
```

#### `perimeter(a)`
Принимает сторону a, возвращает периметр квадрата по формуле `P = 4*a`

Параметры:
- `a` : Сторона квадрата

Возвращаемое значение:
- `4*a` : Периметр квадрата

Пример вызова:
```python
res = perimeter(4)
print(res)  # 16
```
